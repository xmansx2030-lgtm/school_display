{% comment %} One bound form field, rendered the same way on every dashboard page: label, required marker, the widget Django produced, an optional hint, then errors. Before this existed each form page spelled the block out by hand, so the required marker, the hint style and the error markup all differed page to page — and three pages showed no errors at all. Always include it with `only`, otherwise a `hint` set by an earlier include leaks into the next one. {% include "dashboard/_field.html" with field=form.title only %} {% include "dashboard/_field.html" with field=form.body hint="…" wide=1 only %} {% endcomment %}
